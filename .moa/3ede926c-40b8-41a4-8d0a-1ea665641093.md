# 인수인계 — 할 일 목록 JSON API 만들기

## 한 일
- `src/todoApi.js`: `createTodoServer({ file })` — node:http 서버. 요청마다 파일을 읽어 `parseTodos`(src/sortTodos.js)로 검증.
  - GET/HEAD /todos → 200 JSON 배열 그대로, 읽기·검증 실패 → 500 {error}, OPTIONS → 204, 다른 메서드 → 405, 없는 경로 → 404. 쿼리 무시. 모든 응답에 CORS 머리.
- `bin/todo-api.js`: `todo-api <파일> [--port N]`, 기본 포트 PORT 환경 변수 또는 3001. todo-group의 fail() 형식.
- 시험: `test/todoApi.test.js`(listen(0) + 전역 fetch, after에서 close), `test/todoApiCli.test.js`(인자 없음·2개 → 종료 1, --port 0으로 켜서 응답 확인 후 종료).
- package.json bin·description, README 절 추가.

## 이유
- 웹 화면이 할 일 목록을 이 API에서 받아 쓰기 때문. 응답 모양은 지시대로 배열 그대로({todos}로 감싸지 않음).

## 바꾼 파일
- src/todoApi.js, bin/todo-api.js, test/todoApi.test.js, test/todoApiCli.test.js, package.json, README.md, 이 메모.
- 기존 CLI·시험·src/sortTodos.js는 바꾸지 않음.

## 스스로 정한 것
- 파일 없음도 500 {error}("파일을 읽을 수 없습니다: …").
- 500·404·405 응답에도 Content-Type JSON. HEAD는 본문 없음.
- 잘못된 --port 값(숫자 아님·65535 초과)은 `todo-api: 포트가 올바르지 않습니다` 종료 1.
